# TICKET-018 — Guest Invite: Generate & Share Link

**Milestone:** M4 — Guests & Social
**Read first:** ARCHITECTURE.md §3.1 (guest_invites table), §3 (Account Structure)
**Depends on:** TICKET-023 (Account screen — this flow is triggered from there)

---

## Objective
Allow a parent to generate a shareable invite link for a guest. The link contains a unique token that the guest uses to join.

---

## Acceptance Criteria
- [ ] "Invite guest" button on Account screen creates a `guest_invites` row via `InsertGuestInvite` mutation
- [ ] Token is generated server-side by Postgres default (`encode(gen_random_bytes(32), 'hex')`)
- [ ] Invite link format: `tinytales://invite?token=<token>` (deep link)
- [ ] After insert, the share sheet opens with the link + message: "Join our Tiny Tales family! [link]"
- [ ] Uses React Native `Share.share()` API
- [ ] Free tier: if the family account already has 2 active guests (status = 'accepted'), show a message: "Upgrade to invite more guests" — do not create a new invite
- [ ] Invited guests shown in a list on the account screen (TICKET-025)

---

## Files to Create
```
apps/mobile/graphql/mutations/
└── InsertGuestInvite.graphql
```

# TICKET-019 — Guest Onboarding: Accept Invite Flow

**Milestone:** M4 — Guests & Social
**Read first:** ARCHITECTURE.md §3 (Account Structure — guest role), §4 (Auth Model)
**Depends on:** TICKET-018, TICKET-004

---

## Objective
When a guest taps the invite link, they are taken to the app, register or log in, and are linked to the family account as a guest.

---

## Acceptance Criteria
- [ ] Deep link `tinytales://invite?token=<token>` handled by Expo Router at `app/invite.tsx`
- [ ] If user is not logged in: show register/login screen, then proceed
- [ ] On auth: call `AcceptGuestInvite` mutation with the token
- [ ] Hasura Action or Postgres function: validate token exists + status = 'pending', create `users` row with `role = 'guest'` and the invite's `family_account_id`, update invite status to 'accepted'
- [ ] On success: navigate to guest feed `app/guest/index.tsx`
- [ ] If token is invalid/revoked: show clear error message "This invite link is no longer valid"
- [ ] If user is already a guest on this account: navigate directly to guest feed

---


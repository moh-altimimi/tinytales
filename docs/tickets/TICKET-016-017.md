# TICKET-016 — Tale Detail View

**Milestone:** M3 — Home & Feed
**Read first:** ARCHITECTURE.md §5
**Depends on:** TICKET-014

---

## Objective
Build the full tale detail screen. Parents see the complete tale; edit/delete controls are parent-only.

---

## Acceptance Criteria
- [ ] `app/(app)/tale/[id].tsx` — fetches tale by ID using `GetTaleDetail` query
- [ ] Displays: child avatar(s) + name(s), author + date, full narrative text, all tags, media gallery (scrollable, full-width images)
- [ ] Reactions summary shown (e.g. ❤️ 3  😂 1) — not interactive yet (TICKET-021)
- [ ] Comments count shown — not interactive yet (TICKET-022)
- [ ] Edit button (pencil icon) — parent role only — navigates back to review step pre-filled (TICKET-017)
- [ ] Delete button (trash icon) — parent role only — shows confirmation dialog, on confirm calls delete mutation and navigates back to home
- [ ] Loading skeleton while fetching
- [ ] Back navigation to home feed

---

## Files to Create
```
apps/mobile/
├── app/(app)/tale/[id].tsx
├── components/MediaGallery.tsx
└── graphql/
    ├── queries/GetTaleDetail.graphql
    └── mutations/DeleteTale.graphql
```

# TICKET-017 — Edit & Delete Tale

**Milestone:** M3 — Home & Feed
**Read first:** ARCHITECTURE.md §5
**Depends on:** TICKET-016

---

## Objective
Allow a parent to edit a posted tale's narrative, tags, and media.

---

## Acceptance Criteria
- [ ] Edit flow reuses `app/(app)/tale/new.tsx` review step, pre-populated with existing tale data
- [ ] Navigate to edit via: `/(app)/tale/new?editId=<id>`
- [ ] On load with `editId`: fetch existing tale, pre-fill narrative, tags, and media thumbnails
- [ ] Save calls `UpdateTale` mutation: updates `narrative`, `title`, `updated_at`
- [ ] Tag changes: delete all existing `tale_tags` for this tale and re-insert the new set
- [ ] Media: newly added photos uploaded and inserted; removed photos deleted from DB (storage cleanup is best-effort)
- [ ] On save success: navigate to `/(app)/tale/[id]` and show success toast

---

## Files to Create
```
apps/mobile/graphql/mutations/
└── UpdateTale.graphql
```

# TICKET-021 — Emoji Reactions

**Milestone:** M4 — Guests & Social
**Read first:** ARCHITECTURE.md §3.1 (reactions table), §5 (GraphQL Conventions — subscriptions)
**Depends on:** TICKET-020

---

## Objective
Allow guests and parents to react to tales with emoji. Reactions update in real time using a Hasura GraphQL subscription.

---

## Acceptance Criteria
- [ ] Reaction bar displayed on tale detail view (both parent and guest views)
- [ ] 5 available emoji: ❤️ 😂 😮 🥹 👏
- [ ] Tapping an emoji: if the user has not reacted with that emoji, inserts a `reactions` row; if they have, deletes it (toggle behaviour)
- [ ] Each emoji shows a count of how many users have reacted with it
- [ ] Active reactions (current user's) shown with yellow highlight / filled state
- [ ] Counts update in real time via `useSubscription` on `OnTaleReactions` subscription
- [ ] Reaction bar also summarised on `TaleCard` in the feed (non-interactive summary only — e.g. ❤️ 3)
- [ ] `InsertReaction` and `DeleteReaction` mutations
- [ ] Hasura permissions: `parent` and `guest` roles can both insert/delete their own reactions (row-level: `user_id = x-hasura-user-id`)

---

## Files to Create
```
apps/mobile/
├── components/ReactionBar.tsx
└── graphql/
    ├── mutations/
    │   ├── InsertReaction.graphql
    │   └── DeleteReaction.graphql
    └── subscriptions/
        └── OnTaleReactions.graphql
```

# TICKET-022 — Comments on Tales

**Milestone:** M4 — Guests & Social
**Read first:** ARCHITECTURE.md §3.1 (comments table), §5 (subscriptions)
**Depends on:** TICKET-020

---

## Objective
Allow guests and parents to leave comments on tales. Comments update in real time.

---

## Acceptance Criteria
- [ ] Comments section below the reaction bar on tale detail view
- [ ] Displays all comments: commenter avatar, name, comment text, relative timestamp
- [ ] Comment input: fixed at bottom of screen, text input + send button
- [ ] Send calls `InsertComment` mutation, optimistically appends to list
- [ ] Comments list updates in real time via `OnTaleComments` subscription
- [ ] Parents can delete any comment on their family account's tales (DELETE permission scoped to `family_account_id`)
- [ ] Guests can only delete their own comments (`user_id = x-hasura-user-id`)
- [ ] Delete: long-press on a comment shows a delete option (for eligible users)
- [ ] Empty state: "Be the first to comment"
- [ ] Keyboard aware — input rises above keyboard on focus

---

    ├── mutations/

        └── OnTaleComments.graphql

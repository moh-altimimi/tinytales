# TICKET-023 — Account Screen Layout + Parent Profile Edit

**Milestone:** M5 — Account & Settings
**Read first:** ARCHITECTURE.md §3 (Account Structure), §7 (File Storage — child-photos bucket)
**Depends on:** TICKET-005

---

## Objective
Build the account screen — the settings hub. Includes parent profile editing. Other sections (children, guests, data) are wired in subsequent tickets but the layout and navigation structure is built here.

---

## Acceptance Criteria
- [ ] `app/(app)/account.tsx` — account screen
- [ ] Navigable from home screen header settings icon
- [ ] Sections with clear headings:
  - **Profile** — parent name, avatar, email; edit inline
  - **Family** — list of children with "Manage" link (→ TICKET-024); "Invite co-parent" button (placeholder alert for v1)
  - **Guests** — guest count + "Manage guests" link (→ TICKET-025)
  - **Subscription** — current plan (Free / Paid), "Upgrade" link (→ TICKET-029)
  - **Data & Privacy** — "Export my data" link (→ TICKET-026), "Delete account" link (→ TICKET-027)
  - **Sign out** button at the bottom
- [ ] Profile edit: tap name or avatar to edit inline
  - Name: text input, saves on blur via `UpdateUser` mutation
  - Avatar: image picker → upload to `child-photos` bucket → `UpdateUser` mutation with new URL
- [ ] Sign out calls `supabase.auth.signOut()`, clears Zustand store, redirects to login

---

## Files to Create
```
apps/mobile/
├── app/(app)/account.tsx
└── graphql/mutations/UpdateUser.graphql
```

# TICKET-024 — Child Profile Management Screen

**Milestone:** M5 — Account & Settings
**Read first:** ARCHITECTURE.md §3.1 (children table)
**Depends on:** TICKET-023, TICKET-006

---

## Objective
Build the screen that lists all children and allows a parent to add, edit, or remove them.

---

## Acceptance Criteria
- [ ] `app/(app)/children.tsx` — children management screen
- [ ] Lists all children with avatar, name, and age (calculated from DOB using `date-fns/differenceInYears`)
- [ ] "Add child" button → navigates to `app/(app)/child/new.tsx` (TICKET-006)
- [ ] Tapping a child → navigates to `app/(app)/child/[id].tsx` (TICKET-006)
- [ ] Swipe-to-delete or long-press delete option on each child row
- [ ] Delete confirmation dialog: "Removing [name] will not delete their tales, but they will no longer appear as a tag option."
- [ ] Delete calls `DeleteChild` mutation — cascades on `tale_children` (child is unlinked from tales but tales are not deleted)
- [ ] Cannot delete the last child if tales exist (show informative error)

---

## Files to Create
```
apps/mobile/
├── app/(app)/children.tsx
└── graphql/mutations/DeleteChild.graphql
```
